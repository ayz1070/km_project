# 화면 시안 및 스크린샷

## 📱 로그인 화면 시안

### 화면 구성
- **헤더**: KOREA MARKERS 브랜드명
- **로그인 카드**: 중앙 정렬된 깔끔한 카드 디자인
- **입력 필드**: 사용자명, 비밀번호
- **알림 메시지**: 로그아웃 성공/로그인 실패 메시지
- **푸터**: 저작권 정보

### 디자인 특징
- **색상**: Bootstrap Primary Blue (#0d6efd) 기반
- **폰트**: Noto Sans KR (한글 최적화)
- **반응형**: 모바일/태블릿/데스크톱 대응
- **접근성**: 적절한 라벨링 및 색상 대비

## 🚪 로그아웃 화면 시안

### 화면 구성
- **헤더**: KOREA MARKERS 브랜드명
- **로그아웃 카드**: 확인 메시지가 포함된 카드
- **아이콘**: 로그아웃을 나타내는 시각적 아이콘
- **버튼**: 로그아웃 확인/취소 버튼
- **푸터**: 저작권 정보

## 🖥️ 대시보드 화면 시안 (Korea Markers 스타일)

### 화면 구성
- **네비게이션**: Korea Markers 브랜드의 프로페셔널한 메뉴
- **히어로 섹션**: 대형 그라데이션 배경의 환영 메시지
- **사업 분야**: 6개 카드로 구성된 주요 사업 영역
- **사용자 정보**: 현재 로그인한 사용자의 상세 정보

### 디자인 특징
- **색상**: Navy(#1a365d)와 Blue(#2b77ad) 기반의 기업형 디자인
- **레이아웃**: Korea Markers 공식 웹사이트와 동일한 구조
- **컨텐츠**: 시스템 통합, 보안, 클라우드 등 기술 서비스 영역
